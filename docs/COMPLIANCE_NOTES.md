# Compliance Notes — RoomFinder Buddy v3.1

## Purpose

This file documents the compliance assumptions used by RoomFinder Buddy v3.1.

RoomFinder Buddy is not a legal advice tool. It is a practical decision-support assistant that helps identify potential red flags in room listings and rental communications.

## Core Compliance Checks

### Holding Deposit

Flag if the requested holding deposit appears to exceed one week’s rent.

### Tenant Fees

Flag if the listing or agent asks for:

- administration fees
- reference fees
- viewing fees
- application fees
- check-in fees
- check-out fees
- general processing fees

### Rental Bidding

Flag if the landlord or agent encourages offers above the advertised rent.

### Rent in Advance

Do not automatically recommend multiple months of rent in advance.

Use a legally safer financial reassurance strategy instead:

- clear applicant profile
- Right to Rent readiness
- work/residence history
- savings or bank-statement evidence if requested
- legally permitted first month rent in advance after signing

### Bills

For shared houses / HMOs, prefer listings where bills are clearly included or clearly explained.

## Disclaimer

This project does not provide legal advice.  
All legal assumptions should be checked against current official guidance before relying on them.
